# Engineering Twin Data

This directory contains personal engineering knowledge
used by Engineering Twin.

It stores:

- identity
- engineering principles
- technical decisions
- project context


## Structure

identity/

Personal engineering profile.


principles/

Long-term engineering beliefs and preferences.


decisions/

Context-specific technical decisions.


projects/

Project-specific context.


## Usage

Copy this directory to create your own Engineering Twin Data.

Example:

engineering-twin-data/

Then customize the files according to your engineering experience.
