# Engineering Twin Data

This directory contains personal engineering knowledge used by Engineering Twin.

## Structure

```text
engineering-twin-data/
├── README.md
├── identity/
├── principles/
├── decisions/
└── projects/
```

### Knowledge Areas

- `identity/` — engineer identity and background
- `principles/` — engineering principles and recurring practices
- `decisions/` — technical decisions and their reasoning
- `projects/` — project-specific engineering context

Knowledge is stored as human-readable Markdown. The directories may be empty when the Twin is newly created.

This README describes the data directory. It is not itself engineering knowledge.

Use `extract-engineering-twin` to populate or update the knowledge in this directory.

## Privacy

This directory contains personal engineering knowledge. Version-controlling it with git is optional and up to you. If you push it to a git remote, keep the repository private.
