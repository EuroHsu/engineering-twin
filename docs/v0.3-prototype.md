# Engineering Twin v0.3 Prototype

Version: 0.3

Status: Draft

Date: 2026-08-28


## 1. Overview

Engineering Twin v0.3 moves from architecture definition into prototype validation.

The goal is to verify that Engineering Twin can provide engineering context to AI coding agents through a practical Skill workflow.

The prototype focuses on:

- Twin Data discovery
- schema validation
- context loading
- AI agent integration flow


## 2. Goals

Engineering Twin v0.3 aims to:

### 2.1 Discover Twin Data

Allow an AI agent to locate an Engineering Twin Data repository.

Discovery priority:

1. Explicit configured path
2. Workspace configuration
3. User configured default location
4. Request user initialization or attachment


### 2.2 Validate Twin Data

Verify:

- twin.yaml exists
- schema version is supported
- required directories are available
- data structure follows the supported schema


### 2.3 Load Relevant Context

Engineering Twin should load context progressively.

Recommended order:

Metadata

↓

Identity

↓

Relevant Principles

↓

Relevant Decisions

↓

Project Context


The prototype should avoid loading unnecessary information into AI context.


## 3. Runtime Flow

```
AI Agent
    |
    | invokes
    v
Engineering Twin Skill
    |
    | discovers and validates
    v
Engineering Twin Data
    |
    | provides context
    v
AI Agent reasoning
```


## 4. Supported Agent

Initial prototype target:

- Claude Code

Future integrations may include:

- MCP compatible agents
- VS Code AI extensions
- Other coding agents


## 5. Context Rules

Engineering Twin provides guidance, not absolute rules.

The AI agent should:

- consider previous decisions
- explain trade-offs
- maintain consistency
- identify conflicts

The AI agent should not:

- blindly follow old decisions
- assume previous solutions are always correct
- modify Twin Data automatically


## 6. Evolution Workflow

```
Observation

↓

Knowledge Candidate

↓

Human Review

↓

Twin Knowledge Update
```

Permanent knowledge updates require human approval.


## 7. Non Goals

Engineering Twin v0.3 does not include:

- backend services
- database storage
- autonomous learning
- automatic Twin modification
- raw conversation storage
- model fine-tuning


## 8. Future Extensions

Possible future work:

- Claude Code Skill implementation
- CLI utilities
- schema validation tooling
- decision candidate assistance
- additional AI agent adapters
